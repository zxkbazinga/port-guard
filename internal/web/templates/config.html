封禁策略

封禁在本应用的代理层即时生效：命中规则的连接会被当场断开，来自被封 IP 的新连接直接拒绝。不依赖爱快封禁 API。

登录爆破防护

接收群晖 / Windows / Ubuntu 转发的登录失败日志（UDP Syslog），同一 IP 在窗口内失败达到阈值即封禁。需在各服务器配置把安全日志发到本应用的 Syslog 端口。

转发代理

串联模式：爱快把外网端口映射到本应用 IP 的监听端口，由代理转发到内网服务。启用后请在「转发代理」菜单手工添加规则。所有连接都过检测引擎，命中当场断开，封禁不依赖任何外部 API。警告：启用后转发端口需要容器已映射（ipkg 默认映射 22300–22349），且本应用故障时这些服务会中断。

端口池是添加转发规则时建议使用的监听端口范围，须在容器已映射的 22300–22349 之内。改这里不影响已建规则。
