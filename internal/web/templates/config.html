检测源

登录爆破防护

接收群晖 / Windows / Ubuntu 转发的登录失败日志，同一 IP 在窗口内失败达到阈值即封禁。需在各服务器配置将安全日志发送到本机的 Syslog 端口。

诱饵端口

ipkg 桥接网络只暴露 22200–22203 四个容器端口。请在爱快「端口映射」里把不用的 WAN 端口 DNAT 到本应用的 同网段 IP:22200–22203（例如 WAN 3389 → 容器 IP:22200）。任何连上来的公网 IP 都是扫描行为；窗口内命中不同诱饵端口达到阈值才动作，私网与白名单 IP 自动跳过。不依赖爱快连接表 API 或日志。

转发代理

串联模式：爱快把外网端口映射到本应用 IP 的监听端口，由代理转发到内网服务。启用后请在「转发代理」菜单添加规则或从爱快映射导入。所有连接都过检测引擎，命中规则当场断开，不依赖爱快封禁 API。警告：启用后转发端口需要容器已映射（ipkg 默认映射 22300–22349），且 port-guard 故障时这些服务会中断。

端口池是「从爱快映射导入」时给新规则分配监听端口的范围，须在容器已映射的 22300–22349 之内。改这里只影响新导入的规则，不影响已建的转发规则；每次导入从起始端口往后找空闲端口。

检测阈值

统计窗口内超过阈值即判定为攻击并自动封禁。数值越大越保守。
