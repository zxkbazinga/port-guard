封禁策略

封禁在本应用的代理层即时生效：命中规则的连接会被当场断开，来自被封 IP 的新连接直接拒绝。不依赖爱快封禁 API。

登录爆破防护

接收群晖 / Windows / Ubuntu 转发的登录失败日志（UDP Syslog），同一 IP 在窗口内失败达到阈值即封禁。需在各服务器配置把安全日志发到本应用的 Syslog 端口。

转发代理

串联模式：爱快把外网端口映射到本应用 IP 的监听端口，由代理转发到内网服务。启用后请在「转发代理」菜单手工添加规则。所有连接都过检测引擎，命中当场断开，封禁不依赖任何外部 API。警告：启用后转发端口需要容器已映射（ipkg 默认映射 22300–22349），且本应用故障时这些服务会中断。

端口池是添加转发规则时建议使用的监听端口范围，须在容器已映射的 22300–22349 之内。改这里不影响已建规则。

HTTPS 证书（代理 TLS 终结）

可以直接在页面上传证书链和私钥，不需要 SSH/SFTP。文件会写入应用持久化目录，容器内默认路径是 /data/certs/fullchain.pem 与 /data/certs/privkey.pem。上传成功后会自动重建转发监听器；只有转发规则勾选「入口 HTTPS」时才会加载证书。

自动推送（推荐 · 配合 Gately 自动部署）

在 Gately 证书自动部署的「复制后执行」里填入下方命令。证书签发/续期后 Gately 会自动把 $certFile / $keyFile 两个文件推到本应用，校验匹配后自动重载，无需 SSH/SFTP、无需登录。

命令已是单行，已自动填入当前 Token；只需把 PORT_GUARD_IP 换成能访问本应用的地址（Gately 在容器内就填容器可达的 IP）。修改 Token 后请点「保存」并刷新本页，命令会自动更新。私钥通过内网传输，请勿用公网明文 HTTP。

自动从内网网关拉取

启用后定时从 gately 网关拉取证书，校验匹配后自动写入并重载监听器。支持返回一个 JSON（字段 cert_pem / key_pem），或分别返回两份 PEM。私钥请求必须走内网 HTTPS，不要走公网明文 HTTP。
